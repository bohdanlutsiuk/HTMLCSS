# Звіт про виконання лабораторної роботи №7: Верстка вебсторінки Courtly

## Основні рішення та зміни

### 1. Структура проєкту та HTML
- Використано семантичну верстку: `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- Застосовано підхід **mobile-first**, що забезпечує коректне відображення на всіх типах пристроїв.
- Реалізовано адаптивне меню для мобільних пристроїв за допомогою легкого JavaScript-скрипта в кінці `index.html` (перемикання стану `aria-expanded` та класу `is-open`).
- Додано метатеги Open Graph та favicon.

### 2. Стилізація та дизайн-токени
- Всі стилі зосереджені в `styles/styles.css`.
- Використано надані дизайн-токени у вигляді CSS-змінних для забезпечення відповідності дизайн-системі.
- Для реалізації адаптивної типографіки та відступів використано функцію `clamp()`, що дозволяє плавно змінювати розміри між viewport 375px та 1440px.
- Додано базове скидання стилів (reset) для забезпечення однакового відображення в різних браузерах.

### 3. Робота з зображеннями
- Для **Hero-зображення** використано `srcset` (версії 800px та 1200px) та атрибут `fetchpriority="high"` для прискорення завантаження першого екрана.
- Для решти зображень застосовано атрибут `loading="lazy"` для оптимізації продуктивності.
- Всім зображенням задано атрибути `width` та `height` для запобігання стрибкам контенту (CLS).

### 4. Адаптивність (Breakpoints)
- **640px (40rem)**: Перехід до 2 колонок у сітці карток та футері.
- **768px (48rem)**: Зміна компонування інформаційного блоку ("Про нас") на дві колонки.
- **1024px (64rem)**: 
  - Навігація в хедері стає горизонтальною.
  - Hero-секція переходить у двоколонковий режим.
  - Форма пошуку розгортається в один рядок.
  - З'являється **Featured Card** (Акцентна картка), яка займає 2x2 клітинки сітки з додатковим контентом (переваги, вільні слоти).

### 5. Додаткові вдосконалення та семантика
- Секцію «Як це працює» (`#how`) переведено з `div` на список `ul/li` для кращої семантичної структури.
- Форма пошуку оновлена: додано `required`, `select` для міста та виду спорту, а також правильний `action`.
- У футері додано прямі посилання `mailto:` та `tel:` для зручності зв'язку.
- Кнопки «Забронювати» замінено на `<button type="button">` та додано `visually-hidden` текст із назвою майданчика для кращої доступності.

## Додані CSS-змінні та класи
- Додано утилітарний клас `.visually-hidden` у `styles.css`.
- Нові змінні не додавалися.

- Перевірено відповідність кольорів, шрифтів та відступів згідно з `SPEC.md`.
- Протестовано адаптивність на основних брейкпоінтах.
- Перевірено валідність HTML5 та CSS3.
- Підтверджено роботу `mailto:` та `tel:` посилань.
