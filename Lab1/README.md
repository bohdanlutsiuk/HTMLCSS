#  Modern web development Lab1: Environment setup 

A simple, responsive web-based game where a plane automatically moves towards the cliff for. Once it reaches it, it crashes. Users can interact with the game by clicking a button to reset the plane's position to the start.

## Features
- Responsive layout for desktop and mobile viewports.
- Smooth animation using `requestAnimationFrame`.
- Interactive reset functionality.

## How to launch locally
1. Clone this repository
```bash
https://github.com/bohdanlutsiuk/HTMLCSS.git
```
2. Navigate to Lab1
3. Open `index.html` in your favourite web browser
